About Hezarfen

Hezarfen is an arcade game inspired by the legendary flight associated with Hezarfen Çelebi. Start from Galata Tower and try to travel as far as possible while collecting coins and building a higher score. Coins can be spent on useful progression options such as magnet effects, extra lives, power-ups and additional levels. Daily login rewards, ad rewards and streak bonuses add more ways to earn resources between flights.

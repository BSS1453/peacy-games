About Up Break

Short description

Pilot a rocket drill, smash colorful platforms, collect stars and coins, unlock country-flag characters and chase global leaderboard scores.

Detailed description

Up Break is a one-touch arcade game where your rocket doubles as a drill. Break through colorful platforms to build your score, keep moving upward and learn the timing needed to survive increasingly demanding level layouts.

Each level can award up to three stars, with every star adding to the score target and encouraging repeat attempts for a better personal best. Progress also grants coins at regular intervals, which can be used to unlock country-flag characters.

Global leaderboards add a competitive layer beyond your own best score. The game is designed for quick mobile sessions across many progressively harder worlds, with rewarded advertising kept optional rather than interrupting normal play.

Up Break FAQ
